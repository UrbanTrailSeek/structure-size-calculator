## 📖 About

Structure Size Calculator measures any selected region in the world and displays dimensions, block count, volume, and surface area — ideal for build planning and schematic export.

---

## ✨ Features
<a name="features"></a>

- **Region Selection** — two-click corner selection like WorldEdit.
- **Dimensions** — X, Y, Z size shown instantly.
- **Block Count** — total non-air blocks in the selection.
- **Volume & Surface** — full and exposed surface area.
- **Material List** — count of each block type.
- **Export** — save region stats to CSV.

> 🔑 **100% free** — no key system, no linkvertise, no ads.
